## TrueAlphaSpiral Ethent v0.1 Introduces Receipt-Bearing Admissibility for AI Execution

**ODESSA, Texas, May 14, 2026** — TrueAlphaSpiral today announced the v0.1 release of **TrueAlphaSpiral Ethent**, an open-source execution and audit framework designed to move AI systems from output-only trust toward scoped, receipt-bearing admissibility.

The v0.1 release introduces a deterministic verification surface for autonomous and agentic software. Instead of treating AI safety as a post-processing filter or a static policy layer, TrueAlphaSpiral Ethent records whether a proposed action was admitted or refused, why the decision occurred, and how the decision can be replayed through an auditable trace.

The project frames this release as an early implementation of a live ethical immune layer for machine execution: probabilistic systems may propose candidate actions, but execution is constrained by source, scope, admissibility, refusal, and receipt.

### Key capabilities in TrueAlphaSpiral Ethent v0.1

- **Receipt-bearing execution:** Admitted and refused actions are represented as auditable artifacts rather than silent success or hidden failure.
- **Human-scoped delegation:** Human intent is narrowed into bounded machine capability through explicit command scope.
- **Refusal integrity:** Out-of-scope or unverified actions are refused before reaching an irreversible execution surface.
- **Wake-linked provenance:** Accepted and rejected transitions can be tied to replayable forensic traces.
- **Developer-accessible release path:** The repository includes a deterministic Day One workflow path for testing, release dispatch, and proof-surface inspection.

"TrueAlphaSpiral Ethent v0.1 is built on a simple rule: execution without admissibility is not intelligence; it is unchecked automation," said Russell Nordland, founder and steward of TrueAlphaSpiral. "This release gives developers a starting point for systems that do not merely produce outputs, but leave receipts for the authority, scope, and decision path behind those outputs."

Developers, researchers, and audit-focused teams can review the v0.1 release materials and repository documentation on GitHub.

### About TrueAlphaSpiral

TrueAlphaSpiral is an open-source architecture for deterministic AI governance, provenance, and refusal-capable execution. The project focuses on converting machine actions into scoped, attributable, replayable events so that autonomous systems can be evaluated by their process, not merely by their final output.
